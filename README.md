# 모임이 아닌, "팀"

Game demo for a team project, 2026 Fall Global Leadership course.

9주차 **Building a Team** 6–10쪽에 나오는 팀의 네 조건(공동 목적, 헌신, 운영 규칙, 상호의존성)을 가상의 3조 이야기로 직접 겪어 보는 교육용 데모입니다.

| 페이지 | 하는 일 |
|---|---|
| `index.html` | 첫 화면. 조건을 누르면 그 조건을 무너뜨린 단톡 한 줄과 망가진 슬라이드가 나온다 |
| `game/` | 조장 시뮬레이터: 조장 민준이 되어 열흘 동안 단톡방에 답하고, 마지막에 발표를 재생한다 |
| `debugger/` | 팀 디버거: 무너진 발표에서 증거를 모으고, 원인 메시지와 무너진 조건을 찾는다 |
| `swipe/` | 모임? 팀?: 팀플 장면 카드 12장을 모임과 팀으로 나누고, 빠진 조건을 고른다 |

- 서버나 빌드 없이 HTML 파일만으로 돌아갑니다. 외부 리소스도 쓰지 않습니다.
- 3조와 조원, 슬라이드 속 수치는 모두 가상입니다.
- 로컬에서 보려면 `index.html`을 브라우저로 열면 됩니다.
