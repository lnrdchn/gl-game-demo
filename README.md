# 3조의 열흘 · 팀이 되는 네 가지 조건

글로벌시대의 리더십론 9주차 **Building a Team** 6–10쪽(공동 목적, 헌신, 운영 규칙, 상호의존성)을 가상의 3조 이야기로 직접 겪어 보는 교육용 데모입니다.

| 페이지 | 하는 일 |
|---|---|
| `index.html` | 첫 화면. 조건을 누르면 그 조건을 무너뜨린 단톡 한 줄과 망가진 슬라이드가 나온다 |
| `game/` | 3조의 열흘: 조장 민준이 되어 단톡방에 답하고, 마지막에 발표를 재생한다 |
| `debugger/` | 팀 디버거: 무너진 발표에서 원인 메시지를 찾고 조건을 고른다 |

- 서버·빌드 없이 HTML 파일만으로 돌아갑니다. 외부 리소스도 쓰지 않습니다.
- 3조와 조원, 슬라이드 속 수치는 모두 가상입니다.
- 로컬에서 보기: `index.html`을 브라우저로 열면 됩니다.
